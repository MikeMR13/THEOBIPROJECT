# Estados de publicación de novelas

Propuesta para Studio: permitir regresar una novela a borrador, reprogramarla con preestreno o publicarla.

La novela privada debe bloquear la lectura por RLS. Un preestreno solo expondrá ficha, fecha y cuenta regresiva, no capítulos. La transición debe ser atómica, exigir los permisos del equipo propietario y conservar las estadísticas y textos.

Pendiente: migración de Supabase y pruebas de cron, recordatorios y permisos en una base de validación aislada.
